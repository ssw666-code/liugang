## UC-01 本地登录

| 字段 | 内容 |
|------|------|
| 用例编号 | UC-01 |
| 用例名称 | 本地登录 |
| 参与者 | 普通开发成员、团队负责人/PM、系统管理员 |
| 前置条件 | 账号已由管理员或演示数据预置；服务已启动 |
| 后置条件 | 会话建立；用户进入默认工作台 |
| 主成功场景 | 1. 用户打开登录页并输入账号密码<br>2. 系统校验凭据<br>3. 登录成功，进入工作台 |

| 追溯 | F-22；A-01 |
| 验收要点 | 三角色均可登录；无第三方登录完整实现（X-03） |

## UC-03 生成个人日报草稿

| 字段 | 内容 |
|------|------|
| 用例编号 | UC-03 |
| 用例名称 | 生成个人日报草稿 |
| 参与者 | 普通开发成员（负责人亦可为自己生成） |
| 包含 | INC-采集三源素材、INC-写入区间快照 |
| 前置条件 | 已登录且当前身份为成员（或具备生成权限）；数据源模式已配置（真实/Mock） |
| 后置条件 | 产生三章半自动草稿；区间快照已固化；失败源有显式标注 |
| 主成功场景 | 1. 用户选择工作日并点击生成<br>2. 系统计算统计区间（Asia/Shanghai）<br>3. 实时拉取三源素材并过滤/归属<br>4. 排除 Bot/CI<br>5. 写入区间快照<br>6. 生成「今日完成 / 进行中 / 问题与风险」草稿 |
| 备选/异常 | A1 无数据 → 预填提示文案仍出草稿（B-01）<br>A2 单源失败 → 其他源继续，失败源标「采集失败」（P-02、P-04）<br>A3 外网不可用 → 可切 Mock（B-03、A-14） |
| 追溯 | F-01～F-10、F-15、F-16；A-02～A-06；P-01、P-02、P-04；B-01～B-03、B-05；IR-01、IR-05、IR-07、IR-11 |
| 验收要点 | 端到端 &lt; 60s（演示规模）；采集为点击时拉取，非后台监听 |
