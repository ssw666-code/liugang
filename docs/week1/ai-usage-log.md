## 使用边界

- AI 输出作为草案和实现辅助，不代替组内需求确认、代码审查或验收签字。
- 未将真实令牌、授权码、Cookie、个人信息或外部平台原始响应提供给 AI。
- 涉及外部 API 的结论必须在第二周以官方文档和实际 PoC 三源核验。
- 每次重要修改应在提交前由本人理解代码行为，并保留测试结果。
