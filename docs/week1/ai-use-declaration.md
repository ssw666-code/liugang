# AI 使用声明

本组允许使用 AI 工具辅助需求整理、方案对比、代码草稿、测试设计和文档润色。所有 AI 产出都必须经过人工审查、运行验证和必要修改后才能提交。

## 本期使用情况

- 工具：Codex。
- 主要用途：开发工程师课程要求提取、工程骨架生成、代码与测试草稿、过程记录起草。
- 数据边界：未提供真实凭证、个人信息或未经脱敏的外部平台数据。
- 责任边界：提交者对所提交代码和文档的正确性、可维护性及合规性负责。

## 人工核验要求

1. 开发负责人逐文件审查骨架与测试，确认能够解释主要代码路径。
2. 需求与架构负责人提供并通过评审后的规范，开发成员只按接口实现并反馈工程可行性。
3. 配置管理员检查提交中不含 `.env`、令牌或个人敏感数据。
4. 重要 AI 会话同步登记到 `docs/week1/ai-usage-log.md`。
