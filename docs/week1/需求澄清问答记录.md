## 问题 4｜个人日报生成规则

**提问：** 生成方式、是否需确认、章节、群消息有效性？

**原始回答：**

- B：半自动草稿，可编辑再确认
- 必须经成员确认/提交才算正式日报
- 章节：abc（今日完成、进行中、问题与风险）
- 群消息：全部纳入再过滤

**追问 4.1：** 谁过滤？自动规则？章节来源？要否明日计划？

**追问回答：** C / D / A / A

**最终确认：**

- 流程：多源采集 → 系统生成草稿 → 成员编辑 → **提交后正式生效**
- 章节：**今日完成 / 进行中 / 问题与风险**（不要明日计划）

- 三章：尽量自动归类，成员再改

## 汇总：仍可能存在的隐含需求 / 后续设计注意点

（访谈未再展开拍板，实现前建议团队内部再定或写进设计说明）

1. 管理员修改「下班时间」后，**已生成历史日报是否重算**未明确——建议历史按生成时快照区间固化。
